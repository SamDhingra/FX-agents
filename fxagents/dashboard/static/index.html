Start a run

On the server:
cd ~/fx-agents
./fx.sh backtest 60                # 60 days
./fx.sh backtest 60 --no-learner   # learner off
./fx.sh backtest 30 --jev live     # real Jev API
It runs in its own low-priority container, so the live bot isn't affected. Progress shows here; a 60-day run takes roughly 30–60 minutes.
Every run replays the same agents as the live bot: the hourly pick (real book) and setup-first (shadow book) side by side.

How news is handled

TIER 1 FOMC, NFP, CPI, PCE, Fed Chair: no entries 30 min before → 30 min after. Winners get their stop moved to breakeven+ 5 min before; everything else is closed. Half size all day.
HIGH no entries 15 → 15 min; open trades protected 2 min before.
MEDIUM no entries 5 → 5 min.
